# Procedimientos y Procesos — Proaudita

Documentación operacional y comercial del ciclo completo del cliente: desde el primer contacto hasta el cierre del proyecto.

## Objetivo

Estandarizar cada punto de contacto para que la operación sea escalable, profesional y replicable — sin depender de que Matías recuerde cada detalle en cada caso.

## Ciclo del cliente (punta a punta)

```
Prospecto → Contacto inicial → Diagnóstico → Propuesta → Contrato → Ejecución → Entrega → Seguimiento
```

## Estructura

```
procedimientos y procesos/
├── flujos/              → diagramas y descripciones de cada etapa
├── formularios/         → formularios de intake, diagnóstico, feedback
├── propuestas/          → templates de propuesta comercial por servicio
├── contratos/           → templates de contrato de servicios
└── guias/               → guías internas de ejecución de proyectos
```

## Servicios con flujo propio

1. **Auditoría de Procesos Contables** — revisión de registros + informe de hallazgos
2. **Tax Advisory** — planificación tributaria + optimización SII
3. **Diagnóstico Financiero** — análisis de estados financieros + recomendaciones
4. **Automatización Contable** — levantamiento + propuesta de implementación
5. **Consultoría en Control Interno** — diseño o revisión de controles

## Principios de operación

- Toda propuesta debe enviarse dentro de 48h post-diagnóstico
- Todo cliente nuevo recibe un onboarding document antes de la primera sesión de trabajo
- Todo proyecto cierra con un informe escrito, aunque sea breve
- La comunicación formal va siempre por email — WhatsApp es para coordinación rápida
